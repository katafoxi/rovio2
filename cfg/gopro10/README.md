# Настройка параметров камеры 
Настройка парамтетров камеры перед съемкой калибровочных и тестовых видео производится через QR-коды.

<details>
<summary>Рекомендуемые настройки с описанием:</summary>

#### **1. Режим съемки:**

- **Разрешение:** `4K` (3840×2160) или `2.7K` (2704×1520) – для баланса между детализацией и производительностью.
    
- **Частота кадров:** `30 fps` (можно 60 fps, если нужна плавность, но это увеличит объем данных).
    
- **FOV (поле зрения):** **Linear (Линейный)** – минимизирует бочкообразные искажения.
    
    - Если Linear недоступен, используйте **Wide (Широкий)** и калибруйте искажения постобработкой.
        

#### **2. Стабилизация:**

- **HyperSmooth:** **Выключить** (алгоритмы VIO сами обрабатывают движение, стабилизация может вносить артефакты).
    
- Если без стабилизации слишком трясется, можно попробовать **HyperSmooth в режиме "On" (не Boost)**.
    

#### **3. Экспозиция и резкость:**

- **Профиль цвета:** **Flat (плоский)** или **Natural** – для сохранения динамического диапазона.
    
- **Резкость:** **Low** или **Medium** – чтобы избежать перешарпа, который может мешать feature extraction.
    
- **ISO Min:** `100` (минимум шумов).
    
- **ISO Max:** `400–800` (чтобы избежать сильного шума в темноте).
    
- **Экспозиция:** `0` (если слишком темно, можно +0.5, но лучше добавить света).
    
- **Баланс белого:** **Native** или фиксированный (например, 5500K).
    

#### **4. Дополнительные настройки:**

- **Битрейт:** **Высокий** (для сохранения деталей).
    
- **Кодеки:** **HEVC (H.265)** – если поддерживается вашим ПО, иначе H.264.
    
- **Запись на карту:** Используйте **быструю карту** (UHS-II или V90).
    

### **Что не использовать:**

- **SuperView** (сильные искажения).
    
- **Высокие ISO** (шум ухудшает трекинг).
    
- **Агрессивную стабилизацию** (HyperSmooth Boost может "ломать" движение).

</details>

# Создание rosbag-файлов

converter [gopro_mp4_to_rosbag](https://github.com/AutonomousFieldRoboticsLab/gopro_ros) - инструмент для создания из снятого видео rosbag-файлов, необходимых для проведения калибровки и проверки работы алгоритма.
```bash
source catkin_ws/devel/setup.sh
roslaunch gopro_ros gopro_to_rosbag.launch gopro_video:="$gopro_video" rosbag:="$bag_file"
```

Запускалки разных видео
```bash
roslaunch rovio rosbagplay_gopro10.launch  bag_name:=GX010012_camcalibr_c.bag  start:=0 duration:=5
roslaunch rovio rosbagplay_gopro10.launch  bag_name:=GX010008_walk_c.bag  start:=0 duration:=5
roslaunch rovio rosbagplay_gopro10.launch  bag_name:=way.bag start:=120 duration:=50
```

Общая последовательность действий:
1) В терминале перейти в папку с конфигурацией `rovio2/cfg/gopro10`
2) Cнять видео
3) Положить в `/rovio2/cfg/gopro10/video_bags_data`
4) !!!!
5) Перед сборкой контейнера !!!!!ОБЯЗАТЕЛЬНО запустить `./UP.sh` для создания файла аутентификации X11.
6) !!!!
7) Собрать контейнер `docker compose build && docker compose run --rm app`
8) Транслировать в rosbag-file. В меню `1.Выбрать и запустить launch-файл -> 1.gopro_to_rosbag.launch ->1.выбрать видео`. 
9)  Запустить ноду `1.Выбрать и запустить launch-файл ->rosbagplay_node_gorpo10.launch`
